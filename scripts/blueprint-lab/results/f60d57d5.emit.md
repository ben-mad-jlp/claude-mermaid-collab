## Blueprint

**New file:** `scripts/blueprint-lab/score.ts` — sibling to `scripts/blueprint-lab/emit.ts` and `corpus.ts`. Read-only lab script; does not touch `diff-contract.ts`, `emit.ts`, or `corpus.ts`.

### Why here / shape

`emit.ts` (scripts/blueprint-lab/emit.ts:106-153) already writes `results/run.json` shaped as:
```ts
{ total, parsed, unparsed: string[], results: EmitResult[] }
// EmitResult = { id, leafKindExpected: DiffLeafKind, contract: DiffContract | null, rawText }
```
`leafKindExpected` is the leafKind `classifyLeafKind` (corpus.ts:71-78) mined from the commit subject/files — i.e. the "actual" kind. `contract.leafKind` (when parsed) is what the blueprint node self-declared. `validateContractForKind` (src/services/diff-contract.ts:99-111) takes `(contract, leafKind)` and returns `{underspecified: true, missingField}` or `{underspecified: false}` — that's the accept/reject signal, checked here against the contract's own declared `leafKind` (self-consistency check, not against the mined kind — the mined kind is only used for the separate match-rate stat).

### Exact contents of `scripts/blueprint-lab/score.ts`

1. Imports `validateContractForKind`, `type DiffContract`, `type DiffLeafKind`, `type DiffRequirementKind` from `../../src/services/diff-contract`.
2. `interface EmitResult` / `interface RunSummary` mirroring emit.ts's shapes (duplicated locally — emit.ts doesn't export them).
3. `export interface ScoreRow { id: string; parsed: boolean; declaredLeafKind: DiffLeafKind | null; actualLeafKind: DiffLeafKind; leafKindMatch: boolean; verdict: 'accept' | 'reject' | 'unparsed'; missingField: DiffRequirementKind | null }`
4. `export function scoreRun(summary: RunSummary): ScoreRow[]` — maps each `EmitResult`:
   - `contract === null` → `verdict: 'unparsed'`, `declaredLeafKind: null`, `leafKindMatch: false`, `missingField: null`.
   - else calls `validateContractForKind(r.contract, r.contract.leafKind)`; `verdict` is `'reject'` when `underspecified === true` (carrying `missingField`) else `'accept'`; `leafKindMatch = r.contract.leafKind === r.leafKindExpected`.
5. `export function summarizeScore(rows: ScoreRow[])` — returns `{ total, parsed, unparsed, accepted, rejected, matchRate }` where `matchRate = matchedCount / parsedRows.length` (0 when `parsedRows.length === 0`, guarding div-by-zero).
6. `function main()` — reads `join(import.meta.dir, 'results', 'run.json')` (same `OUT` convention as emit.ts:22), calls `scoreRun`/`summarizeScore`, writes `results/score.json` with `{ totals, rows }`, and prints one line per case plus a totals line, following emit.ts's `console.log` mark-per-case convention (emit.ts:138).
7. `main()` invoked at module bottom, matching emit.ts's top-level `main();` (emit.ts:154).
