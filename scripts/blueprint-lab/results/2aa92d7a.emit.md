## Blueprint: GC orphan `collab/epic/*` branches with no live epic todo

### Root cause

`gcEpicBranches` (`src/services/landed-epic-sweep.ts:145-175`) only iterates `report.epics`, which `buildEpicBranchStatus` (`src/services/epic-branch-status.ts:99-155`) builds by walking **live epic todos** and deriving `collab/epic/<id8>` from each todo's id (`epicBranchName`, `epic-branch-status.ts:90-92`). A branch whose epic todo has been deleted/dropped/never-loaded is structurally invisible to this loop — `report.epics` never contains it, so it can never be flagged or deleted. These are exactly the 29 fully-on-master orphans crit-7's live measurement found still present after a sweep (mission b90bfa21, friction 4d458625).

### Change shape

**1. `src/services/landed-epic-sweep.ts` — extend `BranchGcRunner` (lines 88-93)**

Add two methods:

```ts
export interface BranchGcRunner {
  revParse(branch: string): string | null;
  deleteBranch(branch: string): boolean;
  /** All refs/heads/collab/epic/* branch names, live-enumerated (not derived from todos). */
  listEpicBranches(): string[];
  /** Commits on `branch` not on `baseRef`; -1 is the probe-failure sentinel (never null — this
   *  return is compared numerically against 0, and a bare `null` would silently coerce). */
  aheadCount(branch: string, baseRef: string): number;
}
```

**2. `makeBranchGcRunner` (lines 113-124)** — implement both against real git, following the existing `runGitLocal` helper (line 104-111):

```ts
listEpicBranches(): string[] {
  const r = runGitLocal(project, ['for-each-ref', '--format=%(refname:short)', 'refs/heads/collab/epic/']);
  if (r.code !== 0) return [];
  return r.stdout.split('\n').map((s) => s.trim()).filter(Boolean);
},
aheadCount(branch: string, baseRef: string): number {
  const r = runGitLocal(project, ['rev-list', '--count', `${baseRef}..${branch}`]);
  if (r.code !== 0) return -1;
  const n = parseInt(r.stdout.trim(), 10);
  return Number.isNaN(n) ? -1 : n;
},
```

**3. `gcEpicBranches` (lines 145-175)** — after the existing epic-derived loop, add an orphan-sweep pass. Build a `handled` set from `report.epics` branch names (this is the dedup: a branch already reachable via a live epic is fully handled by the first loop and must not be touched again), then enumerate all refs and process the ones the first loop never saw:

```ts
export function gcEpicBranches(
  project: string,
  opts: { probe?: GitProbe; runner?: BranchGcRunner; baseRef?: string; now?: () => string } = {},
): GcEpicBranchesResult {
  const probe = opts.probe ?? makeGitProbe(project);
  const runner = opts.runner ?? makeBranchGcRunner(project);
  const baseRef = opts.baseRef ?? 'master';
  const now = opts.now ?? (() => new Date().toISOString());

  const todos = listTodos(project, { includeCompleted: true });
  const report = buildEpicBranchStatus(todos, probe, baseRef, project);

  const deleted: string[] = [];
  const flagged: string[] = [];
  let skipped = 0;

  const handled = new Set(report.epics.map((e) => e.branch));

  for (const e of report.epics) {
    if (!e.exists) { skipped++; continue; }
    if ((e.ahead ?? 0) > 0) { flagged.push(e.epicId); continue; }
    const tip = runner.revParse(e.branch);
    if (tip == null) { skipped++; continue; }
    if (runner.deleteBranch(e.branch)) {
      appendRecoveryLog(project, e.branch, tip, now());
      deleted.push(e.branch);
    } else {
      skipped++;
    }
  }

  // Orphan pass: branches with no corresponding live epic todo (deleted/dropped/never-loaded)
  // are structurally absent from report.epics — enumerate refs directly and GC by the same
  // fail-closed rule (delete only proven ahead===0; flag ahead>0 or a probe error).
  for (const branch of runner.listEpicBranches()) {
    if (handled.has(branch)) continue;
    const ahead = runner.aheadCount(branch, baseRef);
    if (ahead === 0) {
      const tip = runner.revParse(branch);
      if (tip == null) { skipped++; continue; }
      if (runner.deleteBranch(branch)) {
        appendRecoveryLog(project, branch, tip, now());
        deleted.push(branch);
      } else {
        skipped++;
      }
    } else {
      // ahead>0 (unlanded work) or ahead<0 (probe error, e.g. -1 sentinel) — both unsafe to
      // delete speculatively; flag for human/supervisor review, same posture as the epic loop.
      flagged.push(branch);
    }
  }

  return { deleted, flagged, skipped };
}
```

Note `flagged: string[]` already holds epic ids for the live-epic path; for orphans there is no epic id, so the branch name itself is pushed — callers of `GcEpicBranchesResult.flagged` must treat entries as "epic id or branch name," which is already true of `deleted` (branch names only). No type change needed; just document the mixed content at the interface (`GcEpicBranchesResult`, lines 95-102) with one added line: `/** Epic ids (live-epic path) or bare branch names (orphan path) ahead>0 or probe-errored. */`.
