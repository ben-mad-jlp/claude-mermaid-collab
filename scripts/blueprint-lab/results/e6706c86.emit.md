## Blueprint: `queuePos` column + enqueue/promote store primitives in mission-store

### Context

`src/services/mission-store.ts` already implements a **one-active-per-session** invariant via `active: boolean` and `activateMission()` (mission-store.ts:485-504), which deactivates every other mission owned by the same session (via `ownerSession`/`assigneeSession`, resolved through `listMissions()` at mission-store.ts:1030). There is currently no way to represent "waiting its turn" — a mission is either active or silently inactive with no ordering. This leaf adds a `queuePos` column (session-scoped FIFO position; `null` = not queued) plus two primitives, `enqueueMission` and `promoteMission`, that manage it. No caller wiring (routes/MCP tools) is in scope — store-layer only.

### Changes

**1. `MissionRow` interface — add `queuePos` field** (mission-store.ts:63, next to `active`)

```ts
/** Session-scoped FIFO queue position, or null = not queued (either active or
 *  plain-inactive). Lower = earlier in line. Set by enqueueMission, cleared by
 *  promoteMission. Distinct from `active`: a queued mission is always active=false,
 *  but an inactive mission need not be queued. */
queuePos: number | null;
```

**5. New primitive `enqueueMission`** — place after `activateMission` (mission-store.ts:504), before the `ConductorSelection` interface

```ts
/**
 * Put a mission at the BACK of its owning session's queue: sets queuePos to one past
 * the current max among that session's already-queued missions (0 if none queued yet),
 * and forces active=false (a queued mission is not the one being driven). Missions
 * owned by a different/no session get queuePos 0 relative to no rivals. Idempotent
 * position-wise only if called once per mission — a second call re-appends it to the
 * back with a fresh position.
 */
export function enqueueMission(project: string, todoId: string): MissionRow {
  const m = getMission(project, todoId);
  if (!m) throw new Error(`mission not found: ${todoId}`);
  const all = listMissions(project);
  const self = all.find((x) => x.node.id === todoId);
  const session = self?.ownerSession ?? self?.assigneeSession ?? null;
  let nextPos = 0;
  if (session) {
    const queuedRivals = all.filter((x) => {
      if (x.node.id === todoId) return false;
      const os = x.ownerSession ?? x.assigneeSession ?? null;
      return os === session && x.mission.queuePos != null;
    });
    if (queuedRivals.length > 0) {
      nextPos = Math.max(...queuedRivals.map((x) => x.mission.queuePos as number)) + 1;
    }
  }
  openDb(project)
    .prepare('UPDATE mission SET queuePos = ?, active = 0, updatedAt = ? WHERE todoId = ?')
    .run(nextPos, nowMs(), todoId);
  return getMission(project, todoId)!;
}
```

**6. New primitive `promoteMission`** — directly after `enqueueMission`

```ts
/**
 * Promote a queued mission to ACTIVE: reuses activateMission's one-active-per-session
 * deactivation, then clears this mission's queuePos (it's no longer waiting — it's
 * driving). Safe to call on a mission that was never queued (queuePos already null).
 * Returns the same "deactivated rival todoIds" list as activateMission.
 */
export function promoteMission(project: string, todoId: string): string[] {
  const deactivated = activateMission(project, todoId);
  openDb(project)
    .prepare('UPDATE mission SET queuePos = NULL, updatedAt = ? WHERE todoId = ?')
    .run(nowMs(), todoId);
  return deactivated;
}
```
